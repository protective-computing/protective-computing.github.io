Release History

This page is the public trail for release-bound documentation changes, governance changes, and accepted RFC outcomes. The goal is simple: accepted proposals should leave a visible historical trace rather than disappearing into edited pages.

How to use this page

  • Each release-note row states what changed and where the change landed.
  • The accepted RFC ledger binds governance decisions to release notes and public artifacts.
  • Rejected or deferred RFCs remain on their issue threads; accepted RFCs must appear here.
